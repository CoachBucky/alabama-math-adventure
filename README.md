# Alabama Math Adventure

Build an app that can be used by k-5 students in Alabama to improve their mathematics performance as required by the Alabama Numeracy act and the ACAP standardized tests.  Start with a focus on 3rd and 4th grade requirements:

Grade 3: Focuses on multiplication and division concepts, fractions as numbers (unit fractions, equivalence), and area/perimeter.

Grade 4: Focuses on multi-digit multiplication and division, fraction equivalence/operations with like denominators, and decimal notation.

We want to create an application that these students can engage with to learn and improve their math performance in a game like setting.
